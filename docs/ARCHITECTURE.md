# TeapotsCool Architecture Index

- **Stack:** Astro 4.16.18 SSG (`output: 'static'`, `trailingSlash: 'always'`), Tailwind CSS 3.4 + Typography, MDX, Zod, TypeScript strict.
- **Design System:** "Editorial Tea House / Modern Japandi" (Impeccable craft) — `#FAF8F5` (`rice`), `#F2EFE9` (`stone`), `#E2DDD3` (`border-subtle`), `#C9C1B3` (`border-strong`), `#1F2421` (`charcoal`), `#4E5650` (`muted`), `#2D5A27` (`matcha`), `#9E472D` (`terracotta-text`), calibrated `Fraunces` optical axes (`opsz`) + `Plus Jakarta Sans` + `JetBrains Mono`, `.hairline-grid` shared-border grids, and 2px `.reading-progress` bar.
- **Brand Identity & Mascot:** Koko (ceramic Kyusu tea spirit with matcha sprout) in `public/favicon.svg`, `public/images/brand/logo-mark.svg`, and 3 illustrations in `public/images/brand/`.
- **Content Collections (`src/content/config.ts`):** `guides` (`buying-guides`: 5, `care-maintenance`: 5, `materials`: 4 — 14 MDX >1,600 words each) and `teapots` (10 curated MDX entries acting as Single Source of Truth for ASIN, Pour/Heat scores, capacity, and specs).
- **SEO & Data:** DataForSEO US (`location_code: 2840`) keyword table stored in `src/data/dataforseo-keywords.json`; cluster registry & Amazon `tag=teapotscool-20` placeholder helper in `src/data/clusters.ts` and `src/lib/clusterUi.ts`.
- **Layouts (`src/layouts/`):** `BaseLayout.astro` (OG/canonical/`noindex`/header/footer/FTC disclosure), `GuideLayout.astro` (Quick Verdict, sticky TOC/ClusterNav/Timer/ad-slot, canonical teapot hydration, JSON-LD `Article` + `BreadcrumbList` + `FAQPage` + `ItemList`), `GalleryLayout.astro` (`Product` + `Review` + `BreadcrumbList`).
- **Reusable Components (`src/components/`):** `AffiliateProductCard.astro` (`AffiliateCard.astro`), `BrewingTimerWidget.astro` (`TeaTimer.astro`), `ClusterNav.astro`, `TableOfContents.astro`, `DisclosureBanner.astro`, `FaqAccordion.astro`, `GalleryFilter.astro`, `JsonLd.astro`.
- **Routes (`src/pages/`):** `/`, `/404.html`, `/gallery/`, `/gallery/[slug]/`, `/guides/`, `/guides/[cluster]/`, `/guides/[cluster]/[slug]/`, `/tools/tea-steeping-timer/`, `/about/`, `/affiliate-disclosure/`, `/privacy-policy/`, `/sitemap.xml` (+ `@astrojs/sitemap@3.1.6` `/sitemap-index.xml`).
- **Hosting & Edge Headers:** Cloudflare Pages (`public/_headers`, `public/_redirects`); PNG assets quantized via Pillow (13.13 MB across 29 assets).
- **Accessibility & Web Standards:** `<search>` landmark in `GalleryFilter.astro`; native `<details>`/`<summary>` without nested headings + `command="--toggle-all"` in `FaqAccordion.astro`; `>= 44px` tap targets; `[hidden]` CSS override for `.flex` cards; zero static USD prices (PA-API compliant).
